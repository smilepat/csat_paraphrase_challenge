# 100-Word Paraphrase Challenge

수능형 100단어 영어 지문을 **가장 짧고 쉬운 영어**로 바꾸는 교실용 팀 대항 게임입니다.
의존성 없는 단일 HTML 파일이라 브라우저로 열기만 하면 바로 수업에 쓸 수 있습니다.

## 사용법

`index.html`을 브라우저로 열면 끝입니다. 설치·빌드·서버 불필요.

## 기능

- **지문 3종 내장** — Speed and Independent Thinking / The Value of Productive Difficulty / Technology and Memory (각 ~100단어, 학습과학 주제)
- **목표 단어 수 선택** — 30 / 25 / 20 / 15단어
- **실시간 단어 수 카운터 + 길이 게이지**
- **자동 채점 (100점 만점)**
  - 핵심 보존 50점 — 핵심어 stem 매칭 커버리지
  - 짧게 쓰기 25점(+보너스 5점) — 목표 대비 초과 단어당 감점, 크게 줄이면 가산
  - 쉬운 표현 25점 — 어려운 어휘 사용 및 평균 단어 길이에 따른 감점
- **피드백 문장** — 몇 단어 더 줄여야 하는지, 어떤 핵심 의미가 빠졌는지 안내
- **BLUE / RED 팀 점수판** — 팀 교대, 점수 적립, 전체 초기화
- **예시 답안 토글** — "정답 하나"가 아님을 명시
- **교사용 문항 편집** — 제목·지문·주제·핵심어·예시 답안을 입력해 새 문항 추가 (세션 한정, 새로고침 시 초기화)

## 채점 설계 메모

자동 점수는 **보조 지표**입니다. 핵심어 매칭은 단순 stem(`ing|ed|es|s` 제거) 기준이라
동의어로 잘 바꿔 쓴 답안을 놓칠 수 있습니다. 의미가 자연스럽게 유지됐는지에 대한
최종 판단은 교사가 하도록 규칙과 피드백 문구에 명시되어 있습니다.
